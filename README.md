# Game QA Portfolio 🎮🔍

Este repositório reúne estudos e práticas pessoais relacionadas a **Quality Assurance aplicado a jogos**.

Estou iniciando meus estudos na área de QA e criei este projeto para praticar conceitos como:

* criação de casos de teste;
* reprodução de bugs;
* documentação de problemas;
* comparação entre resultado esperado e resultado obtido;
* investigação de possíveis causas;
* organização de evidências;
* testes de diferentes cenários e condições.

Como tenho interesse em QA para jogos, alguns dos estudos utilizam mecânicas inspiradas em **Minecraft Bedrock**.

> Os casos identificados como "simulados" foram criados exclusivamente para estudo e não representam bugs encontrados em produtos ou projetos reais.

## Estrutura

### Bug Reports

Relatórios de bugs simulados ou encontrados durante testes, contendo:

* ambiente;
* pré-condições;
* passos para reprodução;
* resultado esperado;
* resultado obtido;
* frequência;
* severidade;
* testes adicionais;
* evidências, quando disponíveis.

### Test Cases

Roteiros criados para verificar o funcionamento de mecânicas específicas de jogos em diferentes situações.

## Objetivo

Meu objetivo com este repositório é desenvolver experiência prática com processos de QA, melhorar minha capacidade de investigação e aprender a documentar problemas de maneira clara para equipes de desenvolvimento.
